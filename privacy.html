3. 저장과 보호

OAuth 인증 자료는 운영자가 관리하는 기기의 비공개 설정 폴더에 저장합니다. 현재 Mac 구성은 폴더 접근을 소유자로 제한하고 인증 파일도 소유자만 읽고 쓸 수 있도록 설정합니다. 인증값을 이 공개 사이트나 공개 저장소에 올리지 않습니다.

수집·분석 자료는 운영자 기기의 로컬 데이터베이스와 파일에 저장될 수 있습니다. 생성된 보고서 또는 사용자가 지정한 내보내기 사본은 운영자가 사용하는 동기화 폴더로 복사될 수 있으며, iCloud를 사용하는 경우 Apple의 동기화 서비스가 해당 사본을 처리합니다.

4. 외부 처리와 AI 분석

API 요청은 해당 기능을 제공하는 Google 서비스로 전송됩니다. YouTube 주간 분석 기능에는 집계표만 생성하는 방식, 로컬 Ollama 분석 방식, 사용자가 선택한 Claude 분석 방식이 있습니다. Claude를 사용하는 경우 분석용 집계표와 요청 내용이 Anthropic 서비스로 전송됩니다. 해당 분석 경로는 댓글·영상 제목 등 인증된 원문 텍스트를 AI 입력에서 제외하도록 구현되어 있습니다.

Google 자료를 판매하거나 광고 타기팅을 위해 제공하지 않습니다. Google API에서 얻은 자료를 범용 AI·머신러닝 모델을 학습시키는 용도로 사용하지 않습니다. 기능별 데이터 전송은 사용자가 요청한 목적과 승인한 범위로 제한합니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송에는 Google API Services User Data Policy의 Limited Use 요구사항이 적용됩니다. 외부 AI 및 동기화 서비스에는 각 제공자의 개인정보처리방침도 적용됩니다: Anthropic, Apple.

현재 개인용 구성에는 수집 자료를 일정 기간 후 일괄 자동 삭제하는 기능이 활성화되어 있지 않습니다. 자료와 분석 이력은 운영자가 삭제할 때까지 남을 수 있습니다. Google 연결을 해제해도 이미 저장한 데이터베이스·보고서·내보내기 사본이 자동 삭제되는 것은 아닙니다.

사용자는 운영자에게 저장 자료와 사본의 삭제를 요청할 수 있습니다. 운영자는 요청 대상을 확인해 관련 기기·보고서·동기화 사본에서 수동 삭제를 처리합니다. 서비스별 보관·갱신·삭제 의무는 별도로 적용되며, 이 안내가 서비스 정책상 보관 기간을 연장하는 것은 아닙니다.
